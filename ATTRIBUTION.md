The four habitat plates (`ocean-stage.png`, `polar-stage.png`,
`wetland-stage.png`, and `savanna-stage.png`) were generated for this project
with OpenAI Image Generation. `forest-stage.png` was generated in the same way
during the original red fox build. They contain no third-party logos or text.

The implementation concept is preserved as
`design/animal-selector-concept.png`.
